# Leon 2.2.0 – Download

Deine eigene KI für Schule und Alltag (Windows).

## Installieren
1. Unter **Releases** → „Leon 2.2.0“ die Datei `Leon-Setup-2.2.0.exe` herunterladen.
2. Doppelklicken. Windows warnt? Klick auf **„Weitere Informationen“** → **„Trotzdem ausführen“** (die App ist nur noch nicht signiert).
3. Installation durchlaufen lassen, Leon startet.
4. In **Einstellungen** deinen OpenAI-Schlüssel eintragen – fertig.
